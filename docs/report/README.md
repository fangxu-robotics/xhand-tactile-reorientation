# Interactive training report

`xhand_training_report.html` is a self-contained page (no build step, no external assets) with the
same material as the Markdown docs plus interactive charts — hover for exact per-iteration values,
toggle series, and switch the learning curves to a table view.

**GitHub does not render HTML files in the repository browser.** Three ways to read it:

1. Clone the repo and open the file in a browser.
2. Enable **GitHub Pages** for this repository (Settings → Pages → deploy from branch, `/docs`
   folder), then open `https://<user>.github.io/<repo>/report/xhand_training_report.html`.
3. Paste the raw URL into <https://htmlpreview.github.io/>.
